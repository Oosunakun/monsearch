## ユーザーストーリーと受入条件

### US1 — 検索結果から「種族・タイプ」を確認して再検索する（P1）

カード検索の利用者として、簡易検索で指定した「種族・タイプ」を、結果画面から詳細検索に戻ったときに確認したい。現在の絞り込みを把握したうえで、続けて検索条件を調整できる。

**独立検証**　簡易検索で検索し、結果から「条件を編集」を開いて、値を変えずに再検索する。

1. **前提** 簡易検索の「種族・タイプ」で「ドラゴン」を検索した。**操作** 結果画面で「条件を編集」を押す。**期待結果** 詳細検索の「種族・タイプ」に「ドラゴン」が表示される。
2. **前提** 「種族・タイプ」と他の条件を含む共有検索結果を開いている。**操作** 「条件を編集」を押し、そのまま「この条件で検索」を押す。**期待結果** 同じ有効条件で再検索され、同じカードデータに対する一致結果が維持される。

### US2 — 詳細検索から条件を追加・変更・解除する（P1）

カード検索の利用者として、詳細検索の「基本情報」で「種族・タイプ」を入力、変更、個別クリアしたい。他の条件を使い続けながら、種族・タイプの絞り込みだけを調整できる。

**独立検証**　詳細検索を直接開き、他の有効条件と併用して「種族・タイプ」の入力・変更・クリア後にそれぞれ検索する。

1. **前提** PC またはスマートフォンで詳細検索を開いている。**操作** 「基本情報」を見る。**期待結果** 「タイプ」の直後に「種族・タイプ」欄があり、空のときは `種族・タイプを入力...` と表示される。入力欄のアクセシブルネームは「種族・タイプ」で、カード名・キーワードと同じ形式で入力と個別クリアができる。
2. **前提** 「種族・タイプ」が空、または復元値があり、他の条件が指定されている。**操作** 新しい値を入力し、「この条件で検索」を押す。**期待結果** 入力だけでは画面が移動せず、検索後は URL の `att` が新しい値を表し、新しい値と他の条件を満たす結果が表示される。
3. **前提** 「種族・タイプ」が入力済みで、他の条件も指定されている。**操作** この行のクリアを押し、「この条件で検索」を押す。**期待結果** クリア時点ではこの欄だけが空になり、画面は移動しない。検索後の URL から `att` が省かれ、他の有効条件だけで絞り込まれる。

### US3 — 日本語入力の確定と検索を使い分ける（P2）

キーボードを使う利用者として、入力が確定した後に Enter で検索したい。IME の変換中や確定時、Enter の長押しでも意図せず検索が始まらない。

**独立検証**　「種族・タイプ」欄で IME を使って入力を確定し、その後に通常の Enter を押す。

1. **前提** 入力欄にフォーカスがあり、日本語 IME で変換中または確定操作中である。**操作** Enter を押す。**期待結果** IME の操作が行われ、詳細検索に留まる。
2. **前提** 入力欄に検索に使う値が確定している。**操作** 通常の Enter を押す。**期待結果** 最新の値で「この条件で検索」と同じ検索を1回実行する。押し続けて発生するリピートでは追加の検索を行わない。

### 境界ケース

- `att` がない URL や有効な値が空の URL から開くと、入力欄は空で個別クリアは無効になる。空白だけを入力して検索した場合も `att` を省く。
- 前後に空白を含む値、日本語や記号を含む値、`att` が複数ある URL は、既存の URL 解釈に従う。重複時は最後の文字列を使い、前後の空白を除いて表示する。再検索でも有効な値の意味を保つ。
- 詳細検索の URL を直接開いた場合も、URL にある `att` を表示する。初期表示で URL 条件の反映が遅れる場合は、先に行った編集を上書きしない。
- 一致するカードがない語を確定して検索すると、既存の0件表示になる。「条件を編集」でその語を変更または解除できる。

## 要件

### 機能要件

- **FR-001** 詳細検索の「基本情報」で、カード分類を問わず「タイプ」の直後に、ラベルと入力欄のアクセシブルネームが「種族・タイプ」、placeholder が `種族・タイプを入力...` のテキスト入力欄を表示する。PC・スマートフォンともにカード名・キーワードの表示形式と操作に合わせる。
- **FR-002** 「条件を編集」での遷移と詳細検索の直接表示では、URL にある有効な「種族・タイプ」条件を入力欄に表示する。値を変えずに再検索すると、元の有効条件を維持する。
- **FR-003** 入力欄の値を追加・変更できる。値があるときの個別クリアでこの欄だけを空にでき、空のときは個別クリアを無効にする。入力・クリアによる変更は明示的な検索操作で適用する。
- **FR-004** 「この条件で検索」または入力欄の通常 Enter で、確定した最新の値を使って検索する。日本語 IME 変換中・確定時の Enter とキーリピートによる検索を抑止する。
- **FR-005** 有効な値は既存の URL パラメーター `att` に反映し、未入力・個別クリア後・空白のみの場合は省く。条件の意味と一致判定は簡易検索と共通とし、他の有効条件を保持する。

### 主な検索条件

- **種族・タイプ**　簡易検索と詳細検索で共通の自由入力条件。既存 URL では `att` で表され、既存の種族・タイプ用検索対象に対して部分一致で絞り込む。
- **他の検索条件**　カード名・キーワードや「タイプ」「種族」の選択など、「種族・タイプ」の入力と独立して指定できる条件。

## 成功基準

- **SC-001** 簡易検索からの条件編集と、他条件を含む共有検索結果からの条件編集の両方で、有効な値を入力欄で確認できる。変更せず再検索した場合、各ケースで元の有効条件と一致カードの集合を維持する。
- **SC-002** 入力・変更・個別クリアの3操作すべてで、結果 URL が操作後の値を表し、同じ値と他の有効条件から期待されるカードの集合を表示する。
- **SC-003** PC 幅とスマートフォン幅の両方で、指定位置・表示文言・入力欄のアクセシブルネーム・入力・個別クリアを確認できる。
- **SC-004** 通常 Enter で1回検索し、IME 変換中、IME 確定時、キーリピートでは検索が0回である。

## 対象外

- 既存 URL の形式、検索対象、文字の正規化、部分一致規則の変更。
- 簡易検索や検索結果画面の UI 変更、既存の「タイプ」「種族」などの選択条件の変更。
- カード名やキーワードを含む既存入力欄の改修。
