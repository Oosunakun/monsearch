# Feature Specification: カードセット収録カード検索

**Feature Branch**: `008-open-card-set-results`

**Created**: 2026-09-01

**Status**: Draft

**Input**: User description: "カードセット一覧を閲覧する利用者として、カードセット名を選ぶことでそのカードセットに収録されたカードの検索結果を開きたい。なぜなら、詳細検索条件を手入力せず、関心のあるカードセットを直感的に確認できるからだ。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - カードセットから収録カードを開く (Priority: P1)

カードセット一覧を閲覧する利用者として、関心のあるカードセット名を選び、そのカードセットに収録されたカードだけを対象とする検索結果を開きたい。これにより、詳細検索画面でカードセット条件を探して手入力することなく、一覧から直感的に収録内容を確認できる。

**Why this priority**: 一覧上のカードセットと収録カードの検索結果を直接つなぐことが、この機能の中心的な利用価値であるため。

**Independent Test**: 収録カードが存在する任意のカードセット名を一覧から選択し、検索結果画面が開いて、選択したカードセットのカードだけが検索対象となっていることを確認することで単独検証できる。

**Acceptance Scenarios**:

1. **Given** 複数のカードセットが表示された一覧を閲覧している、**When** 利用者が一つのカードセット名を選択する、**Then** 選択したカードセットだけを検索条件とするカード検索結果が開く。
2. **Given** 選択したカードセットに収録カードが存在する、**When** 検索結果が表示される、**Then** そのカードセットに収録されたカードが結果として表示され、別のカードセットだけに収録されたカードは表示されない。
3. **Given** 同じ表示名を持つカードセットが複数存在する、**When** 利用者がそのうち一つの一覧項目にあるカードセット名を選択する、**Then** 選択した一覧項目に対応するカードセットの検索結果が開く。
4. **Given** トップページまたはレギュレーション情報画面のカードセット一覧を閲覧している、**When** 利用者が同一のカードセット名を選択する、**Then** どちらの一覧からも同じ意味の検索条件を持つカード検索結果が開く。
5. **Given** desktop または mobile でカードセット一覧を閲覧している、**When** 利用者が同一のカードセット名を選択する、**Then** 表示形式にかかわらず同じ意味の検索条件を持つカード検索結果が開く。

---

### User Story 2 - 結果がない場合も選択内容を確認する (Priority: P2)

カードセット一覧を閲覧する利用者として、選択したカードセットに表示可能な収録カードがない場合でも、選択したセットを条件に検索したことを理解したい。これにより、操作が失敗したのか、該当結果がないのかを判断できる。

**Why this priority**: データが未登録または表示対象外の場合にも、利用者が迷わず次の操作へ進める状態を保証するため。

**Independent Test**: 表示可能な収録カードがないカードセット名を選択し、選択したカードセット条件を保った検索結果画面に結果なしの状態が示されることを確認することで検証できる。

**Acceptance Scenarios**:

1. **Given** 表示可能な収録カードがないカードセットが一覧に表示されている、**When** 利用者がそのカードセット名を選択する、**Then** 選択したカードセットを条件とする検索結果画面が開き、結果がないことが示される。
2. **Given** カードセット一覧を閲覧している、**When** 利用者がカードセット名以外の備考または発売日を選択する、**Then** カード検索結果への移動は発生しない。

---

### User Story 3 - 検索結果を再利用する (Priority: P3)

カードセット名から検索結果を開いた利用者として、その検索結果を再読み込み、ブックマーク、別 tab、または共有された場所から開き直しても、選択した同一カードセットの条件を再現したい。これにより、一時的な画面状態に依存せず検索結果を継続利用できる。

**Why this priority**: 一覧からの検索導線を、既存の再利用可能なカード検索結果と同じ性質に保つため。

**Independent Test**: カードセット名から開いた検索結果の場所を再読み込みし、さらに新しい閲覧状態で直接開き、いずれも選択した同一カードセットだけが検索条件として復元されることを確認することで単独検証できる。

**Acceptance Scenarios**:

1. **Given** カードセット名からカード検索結果を開いている、**When** 利用者がその場所を再読み込みする、**Then** 選択した同一カードセットだけを条件とする検索結果が再現される。
2. **Given** カードセット名から開いた検索結果をブックマーク、別 tab、または共有された場所から開く、**When** 新しい閲覧状態でその場所が読み込まれる、**Then** 選択した同一カードセットだけを条件とする検索結果が再現される。

### Edge Cases

- カードセット名に日本語、空白、記号が含まれていても、選択したカードセットとの対応を失わず検索できる。
- 同名のカードセットが複数存在しても、選択していないセットを検索条件へ混入させない。
- 一つのカードが複数のカードセットに収録されている場合、そのうち選択したカードセットに収録されていれば検索対象となる。
- 選択したカードセットに表示可能なカードが一件もない場合でも、検索結果画面を開き、結果なしの状態を示す。
- 一覧項目に検索対象として有効なカードセット情報がない場合、そのカードセット名から不正確な検索結果を開かない。
- カードセット名を連続して選択した場合、それぞれの選択では最後に選択したカードセットだけが検索条件となる。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: カードセット一覧は、各有効な一覧項目のカードセット名を、収録カードの検索を開始できる選択対象として提示しなければならない。
- **FR-002**: 利用者がカードセット名を選択したとき、選択した一覧項目に対応するカードセットだけを条件としたカード検索結果画面を開かなければならない。
- **FR-003**: カードセット一覧から開始する検索へ、利用者が指定していないほかの詳細検索条件を追加してはならない。
- **FR-004**: 検索結果は、選択したカードセットに収録された表示可能なカードを対象とし、選択したカードセットに収録されていないカードを除外しなければならない。
- **FR-005**: 同じ名称のカードセットが複数存在する場合でも、選択した一覧項目に対応するカードセットを一意に検索対象としなければならない。
- **FR-006**: カードセット名に日本語、空白、または記号が含まれていても、選択したカードセットの意味を保持しなければならない。
- **FR-007**: 選択したカードセットに表示可能な収録カードがない場合、選択した条件を保った検索結果画面で結果がないことを示さなければならない。
- **FR-008**: 備考、発売日、およびカードセット名ではない一覧領域の選択によって、収録カード検索を開始してはならない。
- **FR-009**: 検索対象として有効なカードセット情報を持たない一覧項目から、不正確なカード検索結果を開いてはならない。
- **FR-010**: この機能は、カードセット一覧の表示内容、既存のカード検索条件の意味、および検索結果の判定規則を変更してはならない。
- **FR-011**: カードセット名による検索操作は、既存のカードセット一覧を表示するトップページおよびレギュレーション情報画面の双方で利用できなければならない。
- **FR-012**: 同一のカードセットをどちらの一覧から選択した場合も、同じ意味のカード検索条件と同じ移動先を生成しなければならない。
- **FR-013**: カードセット名による検索操作は desktop と mobile の双方で利用でき、表示形式にかかわらず同じ意味のカード検索条件を生成しなければならない。
- **FR-014**: カードセット名から開いた検索結果は、再読み込み、ブックマーク、別 tab、および共有された場所からの再表示後にも、選択した同一カードセットの検索条件を復元しなければならない。

### Key Entities

- **カードセット**: カードを収録する製品またはまとまり。一覧上の名称、略称、備考、発売日、および同名セットを区別できる識別情報を持つ。
- **収録カード**: 一つ以上のカードセットに含まれ、カード検索結果の表示対象となるカード。
- **カードセット一覧項目**: 一つのカードセットを一覧上で表し、利用者が検索対象として選択するカードセット名を含む項目。
- **カード検索条件**: 検索結果の対象を決定する条件。この機能では、一覧で選択した一つのカードセットのみを指定する。
- **検索結果の場所**: 選択したカードセット条件を保持し、再読み込みや別の閲覧状態でも同じ検索を再現できる場所。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 利用者は、カードセット一覧の表示から2回以内の操作で、選択したカードセットの検索結果を開ける。
- **SC-002**: 有効なカードセットを対象とする代表ケースの100%で、選択したカードセットだけが検索条件となり、別のセットだけに収録されたカードは結果へ含まれない。
- **SC-003**: 通常の利用環境で、カードセット名を選択してから検索結果を確認可能になるまでが、測定の95%以上で1秒以内である。
- **SC-004**: ユーザビリティ確認の参加者の90%以上が、説明なしで一覧から目的のカードセットを選び、一回の試行で収録カードの検索結果を開ける。
- **SC-005**: 同名、特殊文字を含む名称、収録カードなしを含む境界ケースの100%で、誤ったカードセットの結果を表示せず、利用者が選択結果を判別できる。
- **SC-006**: トップページ、レギュレーション情報画面、desktop、mobile の全検証組み合わせで、同一カードセットから生成される検索条件と移動先が100%一致する。
- **SC-007**: 再読み込み、ブックマーク、別 tab、および共有相当の全検証ケースで、選択した同一カードセットだけの検索条件が100%再現される。

## Assumptions

- カードセット一覧およびカード検索結果画面は既存機能として利用可能である。
- 対象となる既存カードセット一覧は、共通のカードセット表を利用するトップページとレギュレーション情報画面である。
- 各一覧項目には、表示名とは別に検索対象のカードセットを一意に特定できる既存情報がある。
- 一覧からの検索は、選択した一つのカードセットだけを検索条件とし、以前の検索条件や既定でない条件を引き継がない。
- 「収録されたカード」は、既存のカード検索におけるカードセット条件と同じ判定規則に従う。
- URL Query の正規形式と解釈の Source of Truth は `docs/architecture/query_specification.md` であり、既存のカード検索による条件の生成と復元はこの仕様に従う。
- 表示可能なカードの範囲、並び順、ページ分割、および結果なし表示は、既存のカード検索結果の規則に従う。
- カードセット一覧の絞り込み、並び替え、カードセット詳細画面の追加、および検索結果から一覧へ戻る専用操作は対象外とする。
